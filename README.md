# Python System Monitoring Lab

## Introduction

This project demonstrates how to monitor server performance and system metrics such as CPU usage, RAM usage, and disk space using Python and the `psutil` library. It also shows how to define thresholds and send automated email alerts to system administrators when limits are exceeded.

## Lab Objectives

By the end of this lab, learners will be able to:

- Monitor CPU, RAM, and disk space using the `psutil` library.
- Define and track custom thresholds for system metrics.
- Trigger email alerts using Mailjet when thresholds are exceeded.
- Integrate third-party libraries into Python scripts.
- Create a basic, extensible system monitoring tool.

## Features

- Real-time system resource tracking
- Threshold-based email alerting
- Simple, beginner-friendly code structure
- Mailjet integration for sending alerts

## Requirements

- Python 3.x
- `psutil` library
- `smtplib` or Mailjet SMTP configuration
- Internet connection for email alerts
